ZkEngine - Vulkan Renderer

C++ Vulkan 1.3

ZkEngine is a game engine that i wrote to learn Vulkan 1.3 and fix mistakes that my previous engine had.This engine makes use of some modern rendering techniques like Dynamic Rendering, Bindless with Descriptor Indexing and Buffer Device Address while also using a more modern shading language Slang. The architecture is being done with the possibility of moving to GPU Driven Rendering and Forward+ Rendering in the future.

Engine Features

The engine currently supports the following capabilities across pipeline initialization, rendering, lighting, and core architecture:

• Editor

  • There is a built-in editor in the engine that you can use by compiling the engine with ZK_EDITOR flag defined

• PBR Renderer

  • Bindless textures with descriptor indexing
  • Single big vertex buffer and index buffer for all geometry
  • Architecture is being made with GPU-driven rendering in mind for future expansion
  • Currently its a simple Forward renderer but will be improved to a Forward+ Renderer with compute shaders in the future.

• Lighting

  • Point lights
  • Directional lights
  • Spot lights
  • Skylight (Image-Based Lighting / IBL)

• Shadows

  • Cascaded shadow mapping for directional lights

• Post-Processing

  • Exposure
  • Saturation
  • Contrast
  • Brightness
  • Tonemappers (ACES, Filmic, Uncharted2)
  • Gamma correction

• World & Systems

  • ECS via entt
  • Physics via Jolt Physics

• Networking

  • Right now the engine is capable of launching as client or server.
  • There is a Chat avaiable to enable clients to communicate.
  • Future plans include actual players moving in the world.

Renderer Architecture

The renderer uploads the entire world state to the GPU via Buffer Device Address (BDA), pushing a single address via push constants that grants shaders direct access to all scene data.

First, ECS data is extracted from the main world into a RenderWorld structure—a pure CPU-side representation of the rendering state. Using the RenderWorld, the engine generates shadow cascades, syncs GPU buffers, fetches current environment parameters, and builds the final draw list executed across all render passes.

The renderer currently performs the following pipeline passes:

  • • Shadow Pass

    Generates cascaded shadow maps for directional lights with Percentage Closer Filtering (PCF).

  • • Depth Pre-Pass

    Populates the depth buffer early to reduce overdraw during main shading passes.

  • • Forward Opaque Pass

    Renders PBR geometry utilizing bindless descriptor indexing and unified vertex/index buffers.

  • • Skybox Pass

    Samples HDRI environment cubemaps for background skylight rendering.

  • • Forward Transparent Pass

    Handles blended geometry rendering.

  • • Post-Processing Pass

    Applies multiple post-processing effects and configurable Tonemappers (ACES, Filmic, Uncharted 2).
